When members fight

Spread is the largest difference between the members' positions. Members "fight" when one pushes one way and another pushes back, which strains a shared axis. Turning torque off releases the whole group, so make sure the load can't fall.

Align before turning Torque Lock on if the members were moved by hand. For members that should agree exactly, set the same center pose on each first (servo → Setup → Set current position as center).

Auto-tune

The servo will make short test moves around its current position, with each candidate setting, and keep the values that give the most accurate and calm motion (no overshoot, wobble or hunting). It tunes stiffness (P), damping (D), start force and dead zone, and takes about 1–3 minutes. Values are applied until power-off; you decide whether to save them at the end.

Mount the real load (camera, counterweight), make sure the arm can swing freely by the test range in both directions, and keep clear. Stop restores the original values.

Use the speed and acceleration you'll move with. Tolerance: how close counts as "on target" (2 steps ≈ 0.18°). Never moves more than 45° from the start.
